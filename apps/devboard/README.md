# DevBoard

**Live:** <https://derlocke-ng.github.io/armory/devboard/>

DevBoard is kiwi-framework's **notices** app, mounted here under Armory's name (`framework: 'notices'` in [`distribution.js`](../../distribution.js)). Its code, browser suite and documentation live in the framework: [`apps/notices`](https://github.com/derlocke-ng/kiwi-framework/tree/main/apps/notices). This folder holds only what Armory lays over it (the favicon) and its catalog entry (`kiwi.manifest`).

`node test/e2e/devboard.mjs` runs the framework's suite against Armory's own site.
