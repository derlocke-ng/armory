# pongjs

**Live:** <https://derlocke-ng.github.io/armory/pongjs/>

pongjs is kiwi-framework's **pong** app, mounted here under Armory's name (`framework: 'pong'` in [`distribution.js`](../../distribution.js)). Its code, browser suite and documentation live in the framework: [`apps/pong`](https://github.com/derlocke-ng/kiwi-framework/tree/main/apps/pong). This folder holds only what Armory lays over it (the favicon) and its catalog entry (`kiwi.manifest`).

`node test/e2e/pong.mjs` runs the framework's suite against Armory's own site.
