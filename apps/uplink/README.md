# Uplink

The framework's [chat](https://github.com/derlocke-ng/kiwi-framework/tree/main/apps/chat) app, mounted here as Uplink: messages to your friends (NIP-17, sealed on your device), groups that stay until their host closes them, and live rooms anyone with the link can join, gone when they empty. This folder holds only what Armory lays over it (the icon). It takes over from EnigmaJS, the old rooms on gun.
